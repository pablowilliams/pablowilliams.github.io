01 / Failed-merger detection in SEC filings

Longstop

Live

Open appSource
Problem

A merger that quietly dies leaves no announcement. The evidence is scattered across 8-K exhibits and proxy fields that disagree with each other.

System

Builds a deal dataset from SEC EDGAR, runs an 8-K rules engine over the filings, and reconciles proxy fields that contradict one another before anything is counted.

What I built

The EDGAR ingestion, the rules engine, the ambiguity resolution and the reconciliation logic.

Why it matters

A dataset you can audit deal by deal, rather than a number you have to trust.

Touchstone

Source
Problem

An assistant that invents one figure is worse than no assistant, because nobody can tell which figure it was.

System

What I built

The retrieval stack, the evidence gate, the deterministic verifier and the adversarial test harness that attacks it.

Why it matters

Hallucinated figures become structurally impossible rather than merely unlikely.
